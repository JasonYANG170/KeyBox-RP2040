## The difference between ESP32C3 version and RP2040 version
1. Developed after the ESP32C3 version, the RP2040 version stores keys entirely locally.

2. The RP2040 version comes with a built-in RTC clock design, eliminating the need for network time correction.

3. The RP2040 version uses USB HID input and does not require a Bluetooth HID connection.

## Features
- ✅Supports importing website keys from the browser
- ✅Support TOTP 2FA real-time verification code binding
- ✅USB HID keyboard emulation
- ✅Support RTC
- ✅Supports setting a 6-digit device password
- ✅Screen-off support
- ✅Supports screen brightness adjustment.
